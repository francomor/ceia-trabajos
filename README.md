# CEIA - Trabajos practicos

Trabajos prácticos de la **Carrera de Especialización en Inteligencia Artificial** (CEIA - FIUBA).

Este repositorio reúne las actividades, notebooks y entregas realizadas a lo largo de la carrera.

## Requisitos

- Python `>=3.11,<3.13`
- [uv](https://docs.astral.sh/uv/) para la gestión del entorno y dependencias.

## Setup

```bash
uv sync
```

Esto crea el entorno virtual e instala todas las dependencias declaradas en `pyproject.toml` (fijadas por `uv.lock`).
